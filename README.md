# Physics 12 Study Hub

See [SETUP.md](SETUP.md) for Supabase configuration and free GitHub Pages deployment.

Files:
- `index.html` — website structure
- `style.css` — responsive styling
- `app.js` — chapter library, search, admin login and resource management
- `config.js` — Supabase project URL and public key
- `supabase.sql` — database table and row-level security policies

GitHub Pages is static hosting; Supabase provides the authenticated admin panel and database. PDFs stay in Google Drive.
